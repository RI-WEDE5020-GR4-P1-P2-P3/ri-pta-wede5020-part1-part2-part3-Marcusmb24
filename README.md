# KicksVault — E-Commerce Web Application

A responsive e-commerce web platform for **KicksVault Retailers**, specializing in premium basketball sneakers and streetwear across South Africa.

---

## 📌 Project Overview
KicksVault provides an interactive storefront built with semantic HTML5, modern CSS3 styling, and modular JavaScript. Features include dynamic product filtering, site-wide dynamic navigation, a persistent cart system, and payment gateway security information.

---

## 📂 Site Structure & Pages
* **`index.html`** — Main storefront with product catalog, search functionality, category filters, and interactive slide-out cart.
* **`about.html`** — Information on KicksVault's brand mission, authenticity guarantees, and delivery services.
* **`founder.html`** — Background on the founder, brand origin, and vision.
* **`blog.html`** — Articles covering sneaker performance, care guides, and court advice.
* **`support.html`** — Customer service FAQ, return policies, and shipping details.
* **`contact.html`** — Contact form and local store details.

---

## 🚀 Key Features
* **Dynamic Product Catalog:** Filter sneakers by category or real-time text search.
* **Slide-Out Cart Drawer:** Interactive cart supporting size selection, dynamic item addition, and real-time total price calculation in ZAR (R).
* **Responsive Design:** Mobile-first layout using modern CSS styling.
* **Payment & Security Information:** Clear breakdown of accepted payment methods and card acquiring security.

---

## 💻 Tech Stack
* **HTML5** — Semantic structuring across all pages.
* **CSS3** — Custom properties, responsive layouts, and modern UI controls.
* **JavaScript (ES6)** — Dynamic rendering, state management, search filtering, and DOM manipulation.

## Part 2 - CSS Styling & Responsive Design Implementation

### Responsive Breakpoints & Viewport Testing
* **Desktop Viewport:** `>= 1024px` (Multi-column CSS Grid layout, full navigation bar).
* **Tablet Viewport:** `768px - 1023px` (2-column adapted grid, scaled padding and font sizes).
* **Mobile Viewport:** `<= 767px` (Single-column layout, flexible image containers, touch-optimized UI).
