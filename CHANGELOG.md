# Changelog - KicksVault Development Record

All notable changes to the KicksVault project are documented in this file.

## [v2.0.0] - Part 2 Implementation (2026-09-16)
### Added
* Integrated responsive CSS media queries for desktop, tablet, and mobile breakpoints.
* Added standard CSS Reset to ensure visual consistency across all modern browsers.
* Added screenshot evidence section in `README.md` for desktop, tablet, and mobile responsive layouts.
* Implemented relative units (`rem`, `em`, `%`) across typography, grid layouts, and container padding.

### Fixed & Updated (Feedback Improvements)
* Resolved all Part 1 feedback items by expanding documentation and structuring GitHub repository files.
* Cleaned up external CSS selectors in `style.css` utilizing cascading rules to minimize redundancy.
* Updated inline references to strictly adhere to Harvard citation standards.

## [v1.1.0] - 2026-08-20
### Added
* Integrated support and contact forms in `support.html` and `contact.html`.
* Implemented interactive cart drawer overlay and shoe size selector buttons.

## [v1.0.0] - 2026-07-15
### Added
* Initial project scaffold with responsive navigation bar and main storefront layout.
* Added product catalog cards for Jordan, Air Force, and Shox models.
